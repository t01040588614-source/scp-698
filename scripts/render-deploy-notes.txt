Render 무료 배포 (Blueprint)
============================

1) GitHub에 이 프로젝트 push (render.yaml 포함)

2) https://dashboard.render.com → New → Blueprint
   → 저장소 선택 → Apply

3) 생성 후 팀 공유 URL (프론트):
   https://marketlens-web.onrender.com
   (실제 이름은 Render 대시보드의 marketlens-web URL)

4) 무료 한계
   - 15분 미사용 시 sleep → 첫 접속 30~60초 cold start
   - Postgres free 90일 후 만료 가능 → 백업/유료 전환
   - Redis 없음 (로그인 rate limit 등은 메모리 폴백)

5) API 키: 배포된 사이트 /tools/integrations 에서 입력

6) 로컬 Docker/Cloudflare 터널과 별개로 "하나 더" 쌓이는 클라우드 주소입니다.
