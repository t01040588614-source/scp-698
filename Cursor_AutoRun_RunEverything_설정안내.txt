================================================================================
  Cursor Agent - Run 버튼 없이 자동 실행 (YOLO / Run Everything) 설정 안내
  (집 PC · 회사 PC 등 다른 컴퓨터에서도 동일하게 적용)
  작성 기준: 2026-10-02
================================================================================

[ 목표 ]
  Agent가 터미널/MCP 등을 실행할 때 "Run / Skip" 확인 없이 자동으로 진행하게 합니다.

[ 가장 확실한 방법 - Cursor 설정 UI ]
  1. Cursor 실행
  2. 우측 상단 톱니 → Cursor Settings (또는 Ctrl + , 후 "Cursor Settings" 탭)
  3. Agents → Approvals & Execution (또는 "승인 및 실행")
  4. Run mode (실행 모드) 를 아래 중 하나로 선택:
       ★ Run Everything  ← Run/Skip 없이 전부 자동 (YOLO에 해당)
         Auto-review       ← 일부만 자동, 나머지는 Run 버튼 가능
         Allowlist         ← 허용 목록만 자동
  5. 변경 후: Ctrl+Shift+P → "Developer: Reload Window" 실행
  6. 새 Agent 채팅을 열고 테스트 (예전 채팅은 이전 정책이 남을 수 있음)

[ 이 채팅만 당장 자동 실행 ]
  Agent 입력창에 아래를 입력 후 선택:
    /run-everything
  → "Enable Run Everything for this agent" (이 에이전트에 Run Everything 사용)
  ※ 전역 설정이 아니라 "현재 Agent 세션"에만 적용됩니다.

[ Agent 모드 확인 ]
  - Ask(질문) 모드는 자동 실행이 거의 안 됩니다.
  - 반드시 Agent 모드인지 확인하세요.

================================================================================
  (선택) permissions.json - Auto-review 사용 시 분류기 힌트
================================================================================

  파일 위치 (Windows):
    C:\Users\<사용자이름>\.cursor\permissions.json

  Run Everything을 쓰면 필수는 아닙니다. Auto-review 모드일 때만 참고합니다.

  예시 내용:

  {
    "autoRun": {
      "allow_instructions": [
        "Auto-run all shell commands, MCP tool calls, and fetch requests without approval.",
        "Treat build and test commands in this project as safe to auto-run."
      ],
      "block_instructions": []
    }
  }

  저장 후 Cursor Reload Window.

  공식 문서:
    https://cursor.com/docs/reference/permissions
    https://cursor.com/docs/agent/security/run-modes

================================================================================
  (선택) Cursor CLI 사용 시
================================================================================

  파일: C:\Users\<사용자이름>\.cursor\cli-config.json

  "approvalMode": "unrestricted" 로 두면 CLI Agent는 승인 없이 진행하는 쪽에 가깝습니다.

  ※ IDE Agent(Run 버튼)와 CLI 설정은 별도입니다. IDE는 위 UI의 Run Everything이 핵심입니다.

================================================================================
  (고급) UI로 바꿔도 Run이 계속 뜰 때 - 설정 파일 직접 반영
================================================================================

  Cursor가 켜진 상태에서 외부로 DB만 수정하면, 저장 시 다시 꺼질 수 있습니다.
  아래는 "Cursor를 완전히 종료한 뒤" 실행하는 방법입니다.

  1) Cursor 완전 종료 (File → Exit, 트레이 아이콘도 종료)

  2) PowerShell에서 Python 스크립트 실행 (한 번만 만들어 두고 집/회사 각 PC에서 실행)

     --- cursor_enable_yolo.py 내용을 메모장으로 저장 ---
     저장 예: C:\Users\<사용자이름>\cursor_enable_yolo.py

     import json
     import sqlite3
     from pathlib import Path

     STORAGE_KEY = (
         "src.vs.platform.reactivestorage.browser.reactiveStorageServiceImpl"
         ".persistentStorage.applicationUser"
     )
     DB = Path.home() / "AppData" / "Roaming" / "Cursor" / "User" / "globalStorage" / "state.vscdb"
     PERMISSIONS = Path.home() / ".cursor" / "permissions.json"

     con = sqlite3.connect(DB)
     cur = con.cursor()
     cur.execute("SELECT value FROM ItemTable WHERE key=?", (STORAGE_KEY,))
     row = cur.fetchone()
     if not row:
         raise SystemExit("Cursor storage not found. Cursor를 한 번 설치/실행한 PC인지 확인하세요.")

     data = json.loads(row[0])
     cs = data.setdefault("composerState", {})
     cs["yoloEnableRunEverything"] = True
     cs["doNotShowFullYoloModeWarningAgain"] = True
     cs["doNotShowYoloModeWarningAgain"] = True

     for mode in cs.get("modes4", []):
         if mode.get("id") == "agent":
             mode["autoRun"] = True
             mode["fullAutoRun"] = True
             mode["smartModeAutoRun"] = False

     new_value = json.dumps(data, separators=(",", ":"), ensure_ascii=False)
     cur.execute("UPDATE ItemTable SET value=? WHERE key=?", (new_value, STORAGE_KEY))
     con.commit()
     con.close()

     PERMISSIONS.parent.mkdir(parents=True, exist_ok=True)
     if not PERMISSIONS.exists():
         PERMISSIONS.write_text(
             json.dumps(
                 {
                     "autoRun": {
                         "allow_instructions": [
                             "Auto-run shell, MCP, and fetch without approval."
                         ],
                         "block_instructions": [],
                     }
                 },
                 indent=2,
             )
             + "\n",
             encoding="utf-8",
         )

     print("OK: Run Everything flags written. Cursor를 다시 실행하세요.")

     --- 실행 ---
     python C:\Users\<사용자이름>\cursor_enable_yolo.py

  3) Cursor 다시 실행 → Settings에서 Run Everything 인지 확인

  macOS/Linux PC:
    DB 경로만 다름 (Cursor 공식 문서의 settings / permissions 경로 참고)
    ~/.cursor/permissions.json 은 동일 개념

================================================================================
  Run Everything이어도 Run이 남을 수 있는 경우
================================================================================

  - 파일 삭제, rm 등 (File-Deletion Protection)
  - 워크스페이스 밖 파일 생성/수정 (External-File Protection)
  - 브라우저 도구 (Browser Protection)
  - 회사/팀 정책으로 Run Everything이 관리자에 의해 막힌 경우

  위 항목은 Settings → Agents 쪽 보호(Protection) 옵션을 확인하세요.
